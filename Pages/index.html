    • Hex Value:
      Ex =
      #ffffff = white

    • RGB value:
      rgb(93,56,145)

    Font Formatting:

    • Font-size

      • 1px
        1 pixel
        static

      • 1pt
        1 point
        static

      • 1em
        100% of parent
        relative size to parent

      • 1rem
        100% of root
        relative size to root

    • Font-weight

      • Keywords:
        Normal, Bold, etc..

      • Relative to parent:
        Lighter, Bolder, etc..

      • Number:
        100-900
